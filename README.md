# Èric o Aleix ¿Quién es quién?
Juego estático, sin instalación ni servidor de datos. Abrir `index.html` o servir esta carpeta con `python3 -m http.server`.

- Portada animada con las seis fotografías originales, ocho caras y fichas abatibles. Pausa y respeto a la preferencia de movimiento reducido.
- Tablero libre: alguien elige en secreto un número, responde sí/no y el resto descarta fichas.
- Reto Èric/Aleix: prepara las ocho respuestas antes de jugar. No se han supuesto identidades a partir de las fotos. La clave se guarda solo en el navegador; se requiere prepararla en cada dispositivo. No es un sistema antitrampas.
- Adaptado a móvil, teclado y proyector; pantalla completa cuando el navegador la permite.

GitHub Actions publica en Pages desde main. Si GitHub no permite activar Pages automáticamente, seleccionar Settings → Pages → Source → GitHub Actions.
