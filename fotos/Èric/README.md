# Fotos de l’Èric
Puja aquí fotos on aparegui només l’Èric. Formats: JPG, JPEG, PNG i WEBP.
Cada fitxer serà una pregunta. El nom del fitxer no es mostrarà al jugador.
Les fotos amb tots dos germans s’han de retallar abans de pujar-les.
En publicar a main, GitHub Actions les incorpora automàticament al joc.
