# Fotos conjuntes

Puja aquí les fotos on apareguin tots dos germans. L’ordre sempre es llegeix **d’esquerra a dreta, tal com es veu la foto**.

- `ea...` → Èric a l’esquerra i Aleix a la dreta. Exemple: `ea_001.jpg`.
- `ae...` → Aleix a l’esquerra i Èric a la dreta. Exemple: `ae_002.png`.

S’accepten majúscules i minúscules (EA, ea, AE, ae), i JPG, JPEG, PNG o WEBP. Les fotos sense prefix vàlid s’ignoren amb un avís en publicar.

El jugador tria «Èric i Aleix» o «Aleix i Èric». Cada foto compta com una pregunta i un punt si s’encerta tot l’ordre. Comparteix els blocs de set amb les fotos individuals. No es revela l’ordre correcte fins que l’administració ho activa.
