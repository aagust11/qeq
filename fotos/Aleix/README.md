# Fotos de l’Aleix
Puja aquí fotos on aparegui només l’Aleix. Formats: JPG, JPEG, PNG i WEBP.
Cada fitxer serà una pregunta. El nom del fitxer no es mostrarà al jugador.
Les fotos amb tots dos germans van a `fotos/Conjuntes/`, amb prefix `ea` o `ae` segons l’ordre d’esquerra a dreta.
En publicar a main, GitHub Actions les incorpora automàticament al joc.
